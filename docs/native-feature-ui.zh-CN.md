# 新增功能界面与 Telegram 原生风格统一

本轮只调整现有页面的配色、布局与控件，不增加功能，不改变消息读取、模型请求、保存或发送规则。

## 设计约定

- 页面使用 Telegram 主题灰底、白色内容分组；标题、正文、辅助说明分别使用主题色、主要文字色和灰色文字色。深色或自定义主题下不写死颜色。
- 设置项、单选、开关、分区标题与页签复用 Telegram 原生控件。主要内容左右留白 21 dp，说明通常为 24 dp。
- 开始总结、应用要求、发送等主要操作使用主题填充按钮；复制、详情、切换配置等辅助操作用平面设置行。删除、清空保持红色与原有确认步骤。
- API、提示词和 UID 排除名单编辑页的保存统一放在顶栏。验证或保存失败时将已有错误提示滚动到可见位置。
- 自定义正文采用 16 sp，说明采用 14 sp；输入框保留原生主题下划线。折叠消息使用聊天服务提示色，并保持至少 48 dp 的触摸区域。
- 主题变化只更新现有视图颜色，不重建表单、不丢弃草稿或选择。弹窗通过视图挂载／卸载订阅和注销主题事件。

## 调整范围

1. 总结中心：原生页签、来源与当前任务设置行；范围、要求、筛选、模型分区。
2. 历史总结：搜索、日期分组、正文预览和元信息层次；详情页区分正文、发送与辅助操作。
3. API 配置、核心要求、UID 排除名单：统一设置行、输入框、帮助信息及顶栏保存。
4. 追问与发送预览：统一字号、间距、主题色和主次操作。
5. 群消息管理、撤回记录和聊天折叠占位：原生分组设置、清晰的发送者／正文／时间层次。
